A method that can return null on some path is called, and its result is dereferenced without a null check. The method may be in another file, in another module, or in a library (for example Map.get, System.getProperty, BufferedReader.readLine). When it returns null, the dereference throws a NullPointerException.

The analysis reads the compiled classes of the whole project, so it finds cases that per-method rules cannot see.

Noncompliant code example

// Config.java
String host(Config c) { return c.props().get("host"); }   // Map.get may return null

// Client.java
int port(Config c) { return host(c).indexOf(':'); }        // Noncompliant

Compliant solution

int port(Config c) {
  String h = host(c);
  return h == null ? -1 : h.indexOf(':');
}
